# Правила для заданий AI Challenge

## Время выполнения скриптов

Каждый стартовый скрипт задания (`dayN_<тема>.py`) по окончании работы печатает в консоль время выполнения.
Демо и тестовые прогоны часто идут 20–40 минут, и по выводу должно быть видно, сколько ушло времени.

Для этого скрипт запускает `main()` через `run_timed` из `run_timer.py`, а не напрямую:

```python
if __name__ == "__main__":
    from run_timer import run_timed
    sys.exit(run_timed(main))
```

`run_timed` печатает строку вида `Время выполнения: 23 мин 14 с (старт 14:02:11, финиш 14:25:25)`
при любом завершении: обычном выходе, `sys.exit()`, ошибке, Ctrl+C. Свой замер времени в скриптах не пишем.

## Публикация в GitHub

Любая просьба закоммитить, запушить, «залить в main» или опубликовать день выполняется по `tasks/PUBLISH_PROMPT.md`,
даже если пользователь промт не упомянул.
- `git push` с компьютера не работает: оттуда к GitHub пропускаются только clone и fetch, push получает 403.
  Не пробуй его — коммит делается на компьютере, а отправка идёт из облака bundle-файлом, как в промте.
- Такая просьба — это и разрешение подключить к сессии репозиторий `liseykin-ivan/AI_Challenge` с доступом push.
