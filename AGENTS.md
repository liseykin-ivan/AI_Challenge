# Правила проекта AI Challenge

Правила для агента в OpenCode. Они перенесены из `CLAUDE.md` (правила для Claude) и дополнены
устройством проекта. `CLAUDE.md` не удаляем: при изменении правил обновляй оба файла, чтобы они не расходились.

## О проекте

Учебный челлендж: каждый день — отдельный скрипт `dayN_<тема>.py`, который развивает агента
предыдущего дня (класс наследуется и расширяется, а не пишется с нуля). Описание дней и параметров
запуска — в `README.md`, тексты заданий — в `tasks/day_<N>.md`, отчёты и выводы — в `results/`.

- Python 3.11+, Windows + PowerShell, зависимости — в `requirements.txt` (`httpx`, `python-dotenv`).
- Запуск — интерпретатором из `.venv`: `.\.venv\Scripts\python.exe dayN_<тема>.py --demo`.
- Код, docstring, комментарии, отчёты и ответы пользователю — на русском, как в существующих файлах.
- Настройки — через `config.load_settings()`, HTTP и повторы — через `LLMClient` из `llm_client.py`.
  Не читай переменные окружения напрямую в скриптах дня и не дублируй логику повторов.
- Новые зависимости добавляй в `requirements.txt`, а не только в `.venv`.

## Модели и мультиагентный режим

Правила выбора моделей, режимов DeepSeek Harness и распараллеливания — в `MODELS.md`.
- По умолчанию — `deepseek-v4.1-flash`; архитектура и крупные этапы — `glm-5.3`, сложный разбор —
  `qwen4-max`, рефакторинг — `kimi-k2.7-code`, механическая работа — `glm-5.3-flash`.
- Мультиагентный режим — только для независимых частей; один файл — один писатель; `git`, публикация
  и живые прогоны — последовательно.
- В DeepSeek Harness — `Workspace Write` + `Standard`; Plan mode — только на проектирование.

## Время выполнения скриптов

Каждый стартовый скрипт задания (`dayN_<тема>.py`) по окончании работы печатает в консоль время выполнения.
Демо и тестовые прогоны часто идут 20–40 минут, и по выводу должно быть видно, сколько ушло времени.

Для этого скрипт запускает `main()` через `run_timed` из `run_timer.py`, а не напрямую:

```python
if __name__ == "__main__":
    from run_timer import run_timed
    sys.exit(run_timed(main))
```

`run_timed` печатает строку вида `Время выполнения: 23 мин 14 с (старт 14:02:11, финиш 14:25:25)`
при любом завершении: обычном выходе, `sys.exit()`, ошибке, Ctrl+C. Свой замер времени в скриптах не пишем.

## Живые прогоны

Прогоны с моделью (обычная игра, `--demo`, `--only lifecycle` / `violations`) запускает пользователь сам:
они нужны ему для записи видео с результатом урока. Без явной просьбы не запускай их.
- Сам можно запускать только проверки без модели: `--demo --only matrix`, тесты кода, чтение готовых отчётов.
- Если для проверки правок нужен живой прогон, попроси пользователя запустить его и прислать отчёт.

## Публикация в GitHub

Любая просьба закоммитить, запушить, «залить в main» или опубликовать день выполняется по `tasks/PUBLISH_PROMPT.md`,
даже если пользователь промт не упомянул.
- Коммит и ветка дня создаются на компьютере, затем обычный `git push` в `main` (и ветку дня).
- Правка вне дня (инструменты, README, промпты) публикуется как обновление: только `main`, без ветки дня.

## Новое задание

Новое задание добавляется по `tasks/ADD_TASK_PROMPT.md`: файл `tasks/day_<N>.md` со сквозным номером дня,
первая строка `# День N — <название>`, раздел `## Постановка задания`, текст задания — дословно.
Существующие файлы не трогай; если файл с таким именем уже есть — остановись и спроси.

## Данные и результаты

- `results/` — отчёт прогона `dayN_<YYYYMMDD_HHMMSS>.md`, сырые ответы `dayN_<YYYYMMDD_HHMMSS>.json`
  и выводы `dayN_conclusions.md`. Новые выводы не перезаписывай молча — сначала спроси.
- `memory/` — рабочая история и состояние агентов, в git не попадает.
- `.env` — ключи; в git не попадает. Значения ключей не выводи в консоль, отчёты и коммиты.
- Временные файлы (бандлы, копии, черновики) не оставляй в папке проекта.

## Правки

- Не удаляй и не переписывай чужие файлы и результаты прошлых дней без просьбы.
- Сохраняй структуру, стиль и имена, принятые в соседних файлах проекта.
- Если проверка или тест не проходят — не обходи их силой, сообщи причину и спроси, что делать.
