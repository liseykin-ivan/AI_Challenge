# Промт: публикация результатов дня

Опубликуй результаты текущего задания AI Challenge в репозиторий.
Сама публикация — только через `tasks/publish_day.py`: он делает коммит в `main`,
создаёт ветку `week_<N>/day_<M>` на том же коммите и отправляет обе одной атомарной операцией.
Git-команды для коммита, веток и push вручную не выполняй.

Перед запуском:
- Проверь, что результаты дня на месте: код, `tasks/week_<N>_day_<M>.md`, отчёты прогонов
  и выводы в `results/`, раздел дня в README (и ссылка на выводы).
- Удали из папки проекта временные файлы (бандлы, тестовые копии, черновики) — в коммит попадёт
  всё, что не исключено `.gitignore`.
- Сообщение коммита запиши в файл **вне** папки проекта, в стиле прошлых дней:
  первая строка `День <M>: <что сделано>`, пустая строка, 2–5 строк о содержимом,
  затем строки атрибуции (Co-Authored-By и др.), если они заданы в сессии.

Запуск:
1. `python tasks/publish_day.py --message-file <файл> --dry-run` — покажет день, ветку,
   список файлов и сообщение. Проверь, что в списке нет лишнего.
2. `python tasks/publish_day.py --message-file <файл> --yes`.
   Номер дня берётся из последнего `tasks/week_*_day_*.md`; другой — `--week N --day M`.

Если скрипт остановился — ничего не обходи и не исправляй силой: сообщи пользователю
причину из его вывода (ветка уже есть, `main` разошёлся с GitHub, найден ключ из `.env` и т. п.).

Если коммит и ветка созданы, но push не прошёл из-за отсутствия доступа к GitHub
(например, в сессии нет учётных данных пользователя), попроси пользователя выполнить
у себя в папке проекта: `python tasks\publish_day.py --push-only`.

В конце сообщи хеш коммита и название ветки.
