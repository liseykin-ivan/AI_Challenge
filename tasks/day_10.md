# День 10 — Управление контекстом: сравнение стратегий

## Постановка задания

🔥 День 10. Управление контекстом: сравнение стратегий

Реализуйте в агенте 2 стратегии управления контекстом и переключатель между ними (третья — summary из Дня 9):

**👉 Стратегия 1: Sliding Window**

- храните только последние N сообщений
- всё остальное отбрасывайте

**👉 Стратегия 2: Sticky Facts / Key-Value Memory**

- введите отдельный блок “facts” (ключ-значение), который хранит важные данные из диалога

(например: цель, ограничения, предпочтения, решения, договорённости)

- обновляйте facts после каждого сообщения пользователя
- в запрос отправляйте: facts + последние N сообщений

**Протестируйте все три стратегии на одном сценарии:**
- 👉 возьмите диалог и список деталей из Дня 9
- 👉 прогоните сценарий на Sliding Window, на Sticky Facts и на summary из Дня 9
- 👉 после каждого прогона задайте вопросы по списку деталей

**Сравните:**
- 👉 сколько деталей помнит агент на каждой стратегии
- 👉 расход токенов
- 👉 сколько кода и вызовов модели требует поддержка каждой стратегии

**Добавьте ветвление диалога:**
- 👉 сохраните checkpoint в диалоге
- 👉 создайте 2 ветки от одного места
- 👉 продолжите диалог в каждой ветке независимо
- 👉 переключайтесь между ветками

**Результат:**
Агент с тремя стратегиями управления контекстом + таблица «стратегия → деталей сохранено / токены / сложность» + вывод, какая стратегия для какого сценария

**Формат:**
Видео + Код
