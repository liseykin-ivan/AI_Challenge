# Промт: добавление нового задания

Добавь новое задание AI Challenge в папку tasks/.
Текст задания передан в сообщении вместе со ссылкой на этот файл.

Правила:
- Имя файла: `day_<N>.md`, где N — сквозной номер дня челленджа (День 7 → `day_7.md`), без номера недели.
  Если номер не указан, возьми следующий после самого большого номера среди файлов `day_*.md` в tasks/.
- Формат — как в tasks/day_1.md: первая строка `# День N — <название задания>`, затем раздел
  `## Постановка задания` с текстом задания.
- Текст задания перенеси дословно: ничего не сокращай и не переформулируй.
  Разрешено только оформить пункты как Markdown-список.
- Существующие файлы не трогай. Если файл с таким именем уже есть — остановись и спроси.

## Мультиагентный режим

Перед работой прочитай `MODELS.md`, разделы 4–5, и действуй по ним.

- Сначала оцени, делится ли задание на независимые части. Создание одного файла задания —
  последовательная задача: если независимых частей нет, выполни её одним агентом и явно укажи это
  в отчёте.
- Если задание делится (сверка текста с источником, проверка формата, ссылок и нумерации), запусти
  независимые проверки параллельно и распредели их по таблице маршрутизации из `MODELS.md`.
- По умолчанию — `deepseek-v4.1-flash`; механические проверки — `glm-5.3-flash`.
- Один файл — один писатель: не давай двум агентам править `tasks/day_<N>.md` одновременно.
- В конце сообщи имя созданного файла и перечисли, какие модели/субагенты работали и что проверено.
