# Промт: добавление нового задания

Добавь новое задание AI Challenge в папку tasks/.
Текст задания передан в сообщении вместе со ссылкой на этот файл.

Правила:
- Имя файла: week_<неделя>_day_<день>.md, в неделе 5 дней. Если номер не указан,
  возьми следующий после последнего файла week_*_day_*.md в tasks/
  (после дня 5 — следующая неделя, день 1).
- Формат — как в tasks/week_1_day_1.md:
  первая строка `# Неделя N · День M — <название задания>`, затем раздел
  `## Постановка задания` с текстом задания.
- Текст задания перенеси дословно: ничего не сокращай и не переформулируй.
  Разрешено только оформить пункты как Markdown-список.
- Существующие файлы не трогай. Если файл с таким именем уже есть — остановись и спроси.
- В конце сообщи имя созданного файла.
