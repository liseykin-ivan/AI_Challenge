# Неделя 1 · День 3 — Разные способы рассуждения

## Постановка задания

🔥 День 3. Разные способы рассуждения

Возьмите 5–10 задач с известным ответом
(логических, алгоритмических или аналитических)

Решите их через API четырьмя способами:
- 👉 получите прямой ответ без дополнительных инструкций
- 👉 добавьте в промпт инструкцию: «решай пошагово»
- 👉 попросите модель сначала составить промпт для решения задачи,
  а затем используйте его
- 👉 создайте в промпте группу экспертов
  (например: аналитик, инженер, критик)
  и получите решение от каждого

Прогоните все четыре способа при двух настройках рассуждения:
- 👉 с минимальным рассуждением (`reasoning.effort: low` / минимальный `budget_tokens` / отключено)
- 👉 с максимальным рассуждением

Сравните:
- 👉 сколько задач решено верно
- 👉 сколько токенов и времени ушло

**Результат:**
Таблица «способ × рассуждение → верных ответов / токены / время» + вывод, какие приёмы промптинга перестают что-либо давать, когда рассуждение включено

**Формат:**
Видео + Код
