# Неделя 1 · День 4 — Температура

## Постановка задания

🔥 День 4. Температура

Выполните запрос с параметрами:
- 👉 temperature = 0
- 👉 temperature = 0.7
- 👉 temperature = 1.2

Возьмите два типа запросов:
- 👉 задачу с одним правильным ответом
- 👉 задачу на генерацию (текст, идеи, варианты названий)

Каждую комбинацию прогоните 5 раз.

Сравните:
- 👉 насколько ответы отличаются между прогонами при одинаковых параметрах
- 👉 сколько раз сломался формат или ответ оказался неверным
- 👉 где разнообразие полезно, а где вредит

Сформулируйте:
- 👉 для каких задач лучше подходит каждая настройка
- 👉 даёт ли `temperature = 0` одинаковый ответ каждый раз

**Результат:**
Примеры ответов с разной температурой и выводы по их использованию

**Формат:**
Видео + Код
